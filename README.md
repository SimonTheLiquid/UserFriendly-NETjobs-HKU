# UserFriendly-NETjobs-HKU
userscript for NETjobs providing option to re-enable text-highlighting and right-click, also a button to search employers' company name on search engine directly

# Install
<a href="https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo">Tampermonkey</a>(Chromium-based) / <a href="https://addons.mozilla.org/en-US/firefox/addon/greasemonkey/">Greasemonkey</a>(Firefox) extension is required to run this script

install <a href="https://greasyfork.org/en/scripts/499454-userfriendly-netjobs-hku">here</a>, or <a href="https://github.com/SimonTheLiquid/UserFriendly-NETjobs-HKU/blob/main/UserFriendly-NETjobs-HKU-1.0.user.js">download</a> and import to extensiom

# Remarks
Users should strictly follow the <a href="https://web2.cedars.hku.hk/jobs/use.php">terms and conditions of NETJobs</a>. Any act violating the terms and conditions is strongly discouraged.

Any comments on this script is welcomed.
